# Source and additions

The retained source, calibration files and tutorial originate from [meminyanik/3D-MIMO-SAR_Imaging, commit 60a08620929ddc35fdc3f09a54da9d77af1a2026](https://github.com/meminyanik/3D-MIMO-SAR_Imaging/tree/60a08620929ddc35fdc3f09a54da9d77af1a2026). The source identifies Muhammet Emin Yanik as developer, Murat Torlak as advisor and The University of Texas at Dallas as the institution.

The original copyright and redistribution-retention notices remain in the numerical files. They require retaining the copyright notice in source redistribution and reproducing it in binary redistribution. This notice records those existing conditions and does not supply a new MIT or BSD grant for the inherited files.

RadarVolume adds documentation, artwork, forwarding wrappers, checks, synthetic exports and a supported reconstruction entry point. The reconstruction function also adds an opt-in physical-coordinate mode described in [the method and input conventions](docs/reconstruction.md); its original notice and default reconstruction path are preserved. These additions are covered separately by [LICENSE-branding](LICENSE-branding).

The original nine-file snapshot matches the pinned upstream version. Eight current retained files match exactly; the reconstruction change is identified above. The related later MIMO-SAR-mmWave-Imaging-Toolbox is not presented as the exact source.
